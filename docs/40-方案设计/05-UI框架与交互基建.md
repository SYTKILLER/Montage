## 1. 总体形态：单页编辑器 + 固定桌面布局

- **页面架构**：遵守 Navigation 红线——`Index` 页作 Navigation 根容器，**不建子路由页**（编辑器是单页应用，所有弹层用应用内 Stack 覆盖层；欢迎态=画布区的内嵌视图，不是路由页）。无 router、无 main_pages 新增条目。
- **布局骨架**（对照源 ContentView，键鼠优先）：

```
┌──────────────────────────────────────────────┐
│ 自绘菜单栏（36vp，Row + Menu）                 │
├──────────────────────────────────────────────┤
│ 工具选项条（44vp，随 session.tool 切换）        │
├───┬───────────────────────────────┬──────────┤
│ 工 │ 画布容器（flex 剩余区）          │ 图层面板   │
│ 具 │ ┌───────────────────────────┐ │ 280vp    │
│ 栏 │ │ Stack:                    │ │ （可拖宽 │
│56 │ │  ① XComponent（GL 画布）    │ │ 分隔条） │
│vp │ │  ② Canvas 覆盖层（几何交互） │ │          │
│   │ │  ③ 浮动面板层（M6 起使用）   │ │          │
│   │ └───────────────────────────┘ │          │
├───┼───────────────────────────────┼──────────┤
│ 状态栏（28vp）：缩放% / 文档尺寸 / 进度 / 忙碌    │
└──────────────────────────────────────────────┘
```

- 自由窗口最小尺寸建议 960×600vp；面板区宽度经分隔条拖动（横向 layoutWeight 分宽规则），范围 [220, 420]vp。
- 布局属性不动画面帧（规范：动画中禁改 width/height/padding/margin）。

## 2. 菜单栏与命令体系（Q11 落地）

**命令表是 UI 的脊柱**：菜单、快捷键、（后续）工具栏按钮共用同一张命令定义表。

```typescript
interface CommandDef {
  id: string;                 // 'file.save' / 'edit.undo' / 'layer.mergeDown' …
  label: ResourceStr;
  shortcut?: ShortcutChord;   // 与快捷键系统同源
  enabledWhen?: () => boolean;// 引擎能力位 + 版本号驱动
  checkedWhen?: () => boolean;
  action: () => void;         // 组装引擎命令 / 打开对话框
}
```

- 菜单栏 = 自绘 Row（`文字 + 下拉箭头`）+ `bindMenu` 下拉；子菜单用 Menu 嵌套（**核验项 M0**：Menu 多级子菜单在 API 24 的表现）。
- 使能态：`historyVersion`/`docVersion`/`engineBusy` 三个 @StorageProp 组合计算（**build 内真实读取**范式），命令表集中求值一次避免每项重复计算。
- v1 菜单清单：文件（新建/打开/保存/另存为/导出 PNG·JPEG）、编辑（撤销/重做）、图像（画布大小/图像大小）、图层（新建/删除/复制/向下合并）、视图（放大/缩小/100%/适配画布）、帮助（关于/快捷键表）。滤镜/选择菜单随里程碑挂命令。
- 已核验对照：`hideNavBar` 不适用（我们根本没有 NavBar 需求，全屏内容）；系统标题栏由自由窗口提供，标题显示文档名（window.setWindowTitle 核验 M0）。

## 3. 快捷键系统（Q12 落地）

```typescript
class ShortcutChord {   // 位编码，源 ShortcutChord 同构
  keyCode: number; modCtrl = false; modShift = false; modAlt = false;
  static fromEvent(e: KeyEvent): ShortcutChord;  // e.key.ctrlKey 等已核验
}
```

- **事件路径**：画布宿主（含全局兜底在页面根）`onKeyEvent` → 查命令表 → 分发；文本输入态先放行（`textEvent` 判定，对应源 KeyboardShortcuts 的 canvasEvent/textEvent 边界）。
- **焦点管理**：画布容器 `focusable(true)` 默认持焦；输入框提交/取消后 `focusControl.requestFocus('canvas')` 归还（源 canvasFocusRequest 语义）。**M0 验证项**：根节点 onKeyEvent 在焦点位于画布子树时是否可达（决定"无焦点也有快捷键"能做到什么程度）。
- **修饰键按住状态**（HeldModifiers 等价）：KeyDown/KeyUp 维护 held 状态（onKeyEvent 对单独修饰键也触发，Q12 已核验字段存在）；供变换检查器 ⌘ 反显等交互。
- v1 固定键表（对齐源/PS 惯例）：V 移动 / B 画笔 / E 橡皮 / L 套索 / W 魔棒 / C 裁剪 / T 文字 / I 取色 / G 渐变 / H 抓手 / M 选框、Ctrl+Z / Ctrl+Shift+Z、Ctrl+N/O/S、Ctrl+0 适配 / Ctrl+1 100%、空格=临时抓手、[ ] 笔刷缩放、X 交换色板。可自定义（冲突校验+录制器）v2。

## 4. 画布交互

**与 PixLume 范式的关系（重要澄清）**：PixLume 三层结构解决的是"ArkTS 节点带 .translate 变换后手势失灵"。本架构中**画布像素的缩放平移发生在 GL 内部**（引擎视口变换），ArkTS 覆盖层直接用视口变换函数把文档坐标换算成 vp 绘制——**不存在带变换的节点**，手势绑在无变换宿主上即可，天然规避该坑。命中检测（手柄/选框角点）由覆盖层代码做几何判断。

- **手势与工具模式绑定**：
  - 导航类手势（PanGesture 平移、PinchGesture 缩放 `fingers:2, distance:1`）仅在 Hand 工具 / 空格临时抓手 / 无笔画工具时激活——用 `onGestureJudgeBegin` 按当前工具仲裁（Parallel 组 + 仲裁范式保留，但多数场景单一手势不冲突）。
  - **笔画事件流走 onTouch 原始事件**（不用 PanGesture）：画笔/橡皮等工具在 PointerDown 开始笔画、Move/Up 持续——笔画需要逐事件坐标+pressure（TouchObject.pressure/tiltX 已核验存在），PanGesture 的离散回调不适合笔刷。绘制中手势全部让位（judge REJECT）。
  - 滚轮：`onAxisEvent`（已核验，`scrollStep`）→ 缩放（锚点=光标位置）。v1 固定"滚轮直接缩放"，可配置后置。
- **临时抓手**：空格按住（keydown 状态）→ 光标切抓手、Pan 激活；松开还原。
- **缩放锚点公式**：标准粘指式 `O = C_now − (C0 − O0)·k`（PixLume F4 定案），作用于引擎视口命令（setViewport）。
- **覆盖层局部重绘**：笔刷光标只清/画新旧两个包围矩形（源 BrushCursorOverlay 增量策略）；蚂蚁线 lineDashOffset 动画 + 脏区更新（轮廓多段线由引擎按 02 §3 供给）。
- **坐标系**：交互全程 vp 基准；GL 视口 px 由密度因子换算；`onAreaChange` 同步（R3.4）。

## 5. 浮动面板与对话框体系

- **FloatingPanel 组件**（Q10 定案的 Stack 覆盖层方案）：标题栏拖动（PanGesture 仅绑标题栏——无变换冲突，拖动改 offset）、关闭按钮、非模态；面板位置/开合状态 @State + Preferences 持久化；`hitTestBehavior` 默认 Block（面板自身），画布区不受影响（面板外区域天然穿透）。
- 承载：Levels/Curves/HueSat/Filter 面板（M6 起）；Camera Raw 停靠式面板后置。
- **模态对话框**（新建画布/画布大小/图像大小/导出）：**统一自绘 Stack 遮罩 + 居中卡片**（半透明遮罩阻断交互，Escape/取消关闭）——比系统 CustomDialog 可控（无 NavDestination 限制问题、无控制器可空性坑），且与浮动面板视觉一致。系统 AlertDialog 仅用于确认类（关闭未保存文档等），走 `getUIContext().showAlertDialog` 规范。
- 表单控件规范沿用知识库：输入框/按钮高 50vp 基线按桌面微调（建议 36vp，桌面密度，**待 M0 视觉定稿**）、Select `.value()` 规范、NumericScrub 等价交互（数值拖拽调参）v2。

## 6. 图层面板

- 结构：List + ListItem（单子节点规则）；行 = 缩略图（Image+PixelMap，64px，thumbToken 去重拉取）+ 名称 + 眼睛（SymbolGlyph `eye`）+ 蒙版/剪贴标记；顶部外观条（不透明度 Slider + 混合模式 Select，`.value()` 规范）；底部操作条（新建/复制/删除）。
- **数据流（知识库双坑规避）**：`docVersion` @StorageProp（build 真实读取）→ 变更时调 `getLayerListSnapshot()` 更新 @State 数组 → ForEach `keyGenerator = \`${id}|${rowRev}\``（防同 id 复用不刷新）。**不用 @Builder 传列表数据**（已定案的坑）。
- 命令：选中/显隐/不透明度/混合模式直发引擎；拖拽重排、右键菜单（bindContextMenu）、内联重命名 → v2。
- 分隔条拖宽：横向 PanGesture 改面板宽度 @State。

## 7. 主题与图标

- **Chrome 固定深色**（推荐，待确认）：专业图像编辑器惯例 + 源项目强制 darkAqua 同款决策；画布区中性深灰（棋盘格对比）；系统弹窗组件自动跟随系统。
- 颜色纪律不变：静态色 `$r('app.color.*')` 双资源 + on 色成对、禁硬编码灰。
- **图标（已实测 SDK 符号表，4027 个，snake_case）**：

| 工具/元素 | sys.symbol | 状态 |
|---|---|---|
| 画笔 | `paintbrush_pointed`（族） | ✓ |
| 橡皮 | `eraser_line` / `eraser_scribble` | ✓ |
| 魔棒 | `wand_and_stars` | ✓ |
| 裁剪/旋转/翻转 | `crop` / `crop_rotate` / `rotate_left` / `horizontal_flip` / `vertical_flip` | ✓ |
| 取色 | `eyedropper` | ✓ |
| 抓手/缩放/移动 | `hand` / `magnifyingglass` / `move` | ✓ |
| 文字 | `textformat` | ✓ |
| 眼睛/图层/标尺/网格 | `eye` / `layer` / `ruler` / `grid` | ✓ |
| 选框 | `Inverse_selection` / `smart_selection_area` | ✓ |
| **套索 / 渐变 / 通用形状 / 光标徽标** | 无直接符号 | **缺口** |

- 缺口处理需你裁决（红线要求）：**豁免自绘 5–8 个工具图标**（SVG 矢量，走 media 资源），其余一律 SymbolGlyph；近似替代方案（套索→`scribble`）观感差，不推荐。裁决后在本项目 NOTICE/日志登记红线例外。
