## 规则

1. **每层定案后再展开下一层**；下一层设计时若发现上层决策有问题，回头修订上层文档并记录修订原因。
2. 所有 API 引用必须标注"已核验/未核验"；未核验的编码前必须过本地 SDK（本轮核验方法：`grep` 本地 SDK d.ts 与 native 头文件，记录 file:line）。
3. 官方开发助手的回答一律视为**线索而非事实**——本轮已发现两处答错（见 01 文档 §2）。
