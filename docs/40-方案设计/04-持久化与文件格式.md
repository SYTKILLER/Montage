## 1. D4.1（修订版）格式策略三件套

### 1.1 PSD 导入 = P0 互换格式（优先级最高）

- **排期提案：提前到 M2.5**（图层合成 MVP 之后、笔刷之前）——PSD 是用户真实工程的入口，"能打开真实 PSD"比"能画笔"更早产生产品价值；且图层合成 MVP 恰好是 PSD 导入的验收器。
- **PSD-1 范围（M2.5）**：栅格图层、图层组（pass-through 语义）、图层蒙版、不透明度 + 混合模式映射（25 种，上游 PSDTypes 已有映射表可移植）、剪贴蒙版（maskSourceID 机制）；边界与上游 PSDReader 一致：仅 8-bit RGB，文本/矢量/智能对象降级为像素 + 转换提示（PSDConversionSheet 对应 UI）。
- **实现路径**：上游 PSD 相关 Swift（PSDReader/PSDChannelCoder/PSDTypes/PSDDocumentBuilder，约 2.5k 行）为**直接 C++ 翻译蓝本**——纯手写解析器、零依赖、规格对齐 Adobe 官方文档；EngineSession.textImage 等宿主接口按 02 命令面重接。
- **PSD-2 范围（后置，06 层排期）**：文本层（EngineData 解析 → 可编辑文本层）、矢量形状（活形状层）、调整层映射（Levels/Curves/HueSat 先行）。
- **PSD 导出 = P1（v2 立项）**：作为"PS 开源替代"，最终必须能存回 PSD 与 Photoshop 用户互换；但**写 PSD**（图层/蒙版/压缩通道编码）工作量显著大于读，且依赖文本/调整层映射（PSD-2）先齐，避免"存出去就降级"。初版导出走自有工程格式 + PNG/JPEG 扁平图。

### 1.2 自有工程格式 = 主存格式（与上游脱钩）

**结论：沿用"manifest.json + 每层 PNG 资产"的包结构（实战验证过的形态），但 format 标识、版本线、扩展名全部自有，自由演进，不承诺上游互操作。**

- 保留该结构的理由：规格完整（版本门控/校验规则/原子替换语义可直接继承为自家规格）、实现简单、与 02 层 TileGrid 正交（保存时瓦片拼装为图层包围盒 PNG）。
- 与上游的差异权利：版本线从我们自己的 v1 起算（不再跟随上游 v11 语义）；未来可无痛演进**瓦片原生增量保存**（O4-3）——版本线在自己手里是这次脱钩买到的最大自由度。
- 格式标识与扩展名（**已定名，2026-10-05**）：项目定名 **Montage（蒙太奇）** → 扩展名 **`.montage`**（查重通过：无图像类标准占用；Steinberg WaveLab 的音频蒙太奇工程为异品类，登记注意项）；格式标识常量 **`com.sytkiller.montage.project`**（与 bundleName 同源）。
- 上游 `.comp` 读取：降级为**可选适配器，后置**——除非将来有用户拿着旧 .comp 文件来（登记 O4-4）。

### 1.3 格式限制与引擎预算

- 工程包校验规则自持（尺寸/层数/文件名匹配/组树校验/剪贴链校验——把上游 validate 规则收编为自家规格）。
- 限制数值沿用上游档位（单边 30000px、总像素 1 亿、10000 层）作为**格式上限**，与引擎运行预算（02 §7）分立；读超预算文件给明确错误。

## 2. D4.2 工程文件的位置与打开/保存流（维持）

默认目录在应用沙箱（Documents/），打开/另存经 DocumentViewPicker（零权限），记住上次目录；已关联 URI 直接覆写；文件关联（双击打开）核验后置。细节见 v1.0 §2（不变）。

## 3. 图像导入导出

| 项 | 方案 | 排期 |
|---|---|---|
| **PSD 导入（PSD-1）** | 上游解析器 C++ 翻译，见 §1.1 | **M2.5（提案）** |

| 自有工程格式读写 | §1.2 | M4 |

## 4. 外部变更检测（定位调整）

产品定位修正后，"外部直写协作"不再是特性承诺，该机制降级为**通用的数据保护**：

- **基线（M4）**：应用回到前台 / 窗口重新激活时比对工程包 digest（SHA256：manifest + 各资产文件名与大小，cryptoFramework 已核验）→ 有未保存修改且外部变更 → "Revert / Keep Mine" 对话框，绝不静默覆盖。
- **增强（后置）**：`fileIo.createWatcher` 对沙箱默认目录的实时监听（URI 路径支持核验通过才做，O4-1）。
- 事件合并/退避/半写包忽略等语义沿用源项目设计。

## 5. 最近项目与偏好（不变）

Preferences Kit 持久化最近列表与工具默认值；无定时自动保存；关闭确认对话框归 05 层。
