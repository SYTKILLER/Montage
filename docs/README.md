# Montage（蒙太奇）项目文档中心

> **项目定位**：**Montage（蒙太奇）**——为鸿蒙平台打造的 Photoshop 级开源替代软件。"蒙太奇"即合成剪辑的艺术，直指图层合成的本质（2026-10-05 定名；查重通过：图像编辑领域无同名独立软件，MontageJS 为 2012–2016 休眠 JS 框架、不同生态，澜起科技 Montage 为芯片行业）。
> 上游 Compositor（macOS 开源图像编辑器）仅作为参考实现与脚手架，不代表产品身份；文件互换以 **PSD 为中心**。
> **约定**：本项目产生的所有文档一律放入本目录，按编号分类归档。
